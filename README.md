## Overview

This repository contains a set of authored documents that together define the Somatic Infrastructure Framework: a conceptual and facilitative approach to understanding how built environments condition physiological, neurological, relational, and ecological outcomes in living human bodies.

The materials herein establish somatic harm as a systems-level variable in infrastructure design and articulate how interdisciplinary collaboration can be guided by biological and embodied requirements—without providing technical designs, engineering specifications, or construction methods.

This repository is intended for reference, attribution, and interdisciplinary orientation.

## Contents

   Core design specification document outlining principles, conditions, and system requirements for somatically-informed infrastructure.

2. **Somatic Harm as an Infrastructural Variable**  
   Conceptual companion paper defining somatic harm as a systems outcome of environmental conditions rather than individual pathology.
